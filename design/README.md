# Handoff: to - 言いあえる関係について

## Overview
「言いにくいことも、お互いに言える関係」をつくるためのコツを、1枚ずつ図解で集めるサイトです。画面はトップ（一覧）とTips詳細の2つです。姉妹サイト「zu - 伝わりやすい形について」（https://craftpaperbag.github.io/zu/）と同じく、**GitHub Pagesで配信する静的サイト**として実装してください。

## About the Design Files
このフォルダの `.dc.html` は、見た目と振る舞いを示す**HTMLのデザイン参照**です。本番コードとしてそのまま使うものではありません。リポジトリは空なので、以下の方針で新しく実装してください。

- 推奨構成：静的サイトジェネレーター（Astro か Eleventy）＋素のCSS。JSは最小限（カテゴリ絞り込み、ランダム、表示モード切替のみ）。
- Tipsは1件1ファイルにする（Markdown＋frontmatter、または `tips.json` のような構造）。図解SVGはTipsごとに `visuals/<slug>.svg`（またはコンポーネント）として分ける。1件追加すれば一覧と前後ナビに自動で反映される形にする。
- URL：トップ `/`、詳細 `/tips/<slug>/`。詳細ページは静的に個別生成する（共有やブックマークのため）。
- GitHub Actionsで GitHub Pages にデプロイする。

参照ファイルをブラウザで開くと動作を確認できます（`support.js` が同じフォルダに必要です）。

## Fidelity
**High-fidelity。** 色、タイポグラフィ、余白、アニメーションは最終案です。数値のとおりに再現してください。

## Interactions & Behavior
- カテゴリ絞り込みはクライアント側で行う。選択状態を `?cat=` クエリに反映すると共有しやすい（任意）。
- 「ランダムに一枚」は詳細ページへ遷移する。詳細ページで押した場合は、いま表示中のTipsを除いて選ぶ。
- ページ遷移時はページの先頭から表示する。
- **図のアニメーション**：詳細では常に再生する。一覧でも再生する（デザイン上の既定値。重ければ一覧だけ静止も可）。
- **prefers-reduced-motion: reduce** のときはすべての `animation` を止める。静止状態は最終フレームに相当する配置で、意味が伝わるように描いてある（参照ファイルの基本属性がそのまま静止画になる）。
- **色に頼らない表示**：`localStorage` のキー `to-cvd`（"1"/"0"）で保持し、ルート要素に属性を付けてCSSで切り替える。ONのときの置き換え：
  - 話す人：`#26262B` の塗り円、線も `#26262B`。
  - 受け取る人：白い塗りに `#26262B` の2.5px輪郭。線は `#8A8690`。
  - 共有されたもの：白い塗りに点線輪郭（1.5px、dasharray 2 2）。線は `#26262B`。共有の場（Tip 3）は `#26262B` の fill-opacity .06、輪郭は点線4 3。
  - 凡例のスウォッチも同じ形（塗り／輪郭／点線輪郭）に切り替える。
  - 参照実装では、SVGの各要素に `data-r` で役割を付けています（`sf` 話す人の塗り / `sl` 話す人の線 / `sb` 話す人の吹き出し / `st` その文字 / `lf` 受け取る人の塗り / `ll` 受け取る人の線 / `lb` 受け取る人の吹き出し / `shf` 共有の塗り / `sht` その文字 / `shl` 共有の線 / `sha` 共有の場）。この方式をそのまま使ってください。
- ボタンはすべて `<button>`、カードは `<a>`。タップ領域は40px以上を確保する。フォーカスリングは消さない。
- 図のSVGには `role="img"` と `aria-label`（`tips.json` の `visualLabel`）を付ける。

## 図解の仕様（`TipVisual.dc.html`）
人は顔のない円で表します。1枚の図で伝える主張は1つだけです。動きは意味を運ぶものに限り、装飾のためのアニメーションは入れません。keyframes・座標・時間は参照ファイルからそのまま移植してください。
- **Tip 1（5秒ループ、viewBox 360×200）**：左では、ボールが受け手の円に当たって外へ跳ね返る。右では、ボールが受け手に収まり（受け手の周りに波紋）、緑の「?」の玉になって話し手へ戻る。中央に縦の区切り線。キャプションは「跳ね返す／受け止めて、問いで返す」。
- **Tip 2（6秒、360×220）**：上では、話し手の線が途中で薄くなり、受け手の線が山形に割り込む。下では、二本の線が並んで伸び、合流点から緑の太線（6px）になって続く。線は `pathLength=1` と `stroke-dashoffset` で描画する。キャプションは「断ち切ってから引く／横に並べて伸ばす」。
- **Tip 3（7秒、360×220）**：話し手が手（線）を挙げると「?」の吹き出しが出る。まわりの受け手4人の吹き出しが順に（0.84秒ずつずれて）ふくらみ、中央の緑の場が広がる。
